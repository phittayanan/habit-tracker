### Not checked on the deployed app

- A day sign changing because of an entry edit or delete (in C-15 the sign did not need to change).
- Keyboard-only use of the screens (only the single keyboard steps named above).
- Edit, delete and create requests across accounts, and a new goal on a retired template through the API.
- Two requests at the same time; ended goals and goals not yet started.

The automated suites in the release CI cover cases of these kinds; that is not a production result.
