# 0091. The goal detail page is a short summary

Status: chosen by projectnewy on 2026-11-27 in [Issue #157](https://github.com/phittayanan/habit-tracker/issues/157) (Q6). To be agreed by phittayanan in the review of the #157 PR.

## Decision

The detail page shows the template name, the current daily target, the start and end dates, the state, days met, the current streak of a goal that has not ended, and the best streak. This answers SRS A-10.

## Options considered

- A. A short summary (chosen).
- B. A summary and a day-by-day history.
- C. The best streak only.

## Why

It uses data the product already has, and the List view already shows the daily history.
