# 0090. The current streak shows on the goals page and on today's calendar cards

Status: chosen by projectnewy on 2026-11-27 in [Issue #157](https://github.com/phittayanan/habit-tracker/issues/157) (Q5). To be agreed by phittayanan in the review of the #157 PR.

## Decision

The current streak shows next to each goal on the goals page, and on the cards of the calendar's day box or panel only when the chosen day is today. This amends ADR 0073 point 2.

## Options considered

- A. The goals page and today in the calendar (chosen).
- B. The goals page only.
- C. The goals page and every calendar day.

## Why

The current streak is a value for now, so it is not shown against a past day.
