## Observations (not findings)

- A template and a P1 goal named "Persistence test" (`times`, 0–10; goal 2026-11-17 → 2026-11-24) existed before our cases. They match no UAT case; the handoff says data may be left by a previous tester.
- UAT-05: the first P1 goal on template `UAT-05-PT` was created with start 2026-11-25 instead of 2026-11-24 (tester input error). It cannot be deleted and a second goal on the same template would overlap, so the case was run on a new template `UAT-05-PT2`. The wrong-date goal (P1 goal id 4) was not used.
- UAT-05: template `UAT-05-PT2` has max **9.86** (E-B2-08), not the 10 the case asks for. The tester typed 9.86 on purpose to see whether a decimal maximum is accepted; it was. This is a deviation from the case setup, not a finding. It does not affect UAT-05 (all values used are 2 to 4).
- UAT-05: progress is shown as "0%" and "50%"; the handoff writes "0.00 %" and "50.00 %". Same values, different display format.
- UAT-06 step 3 was recorded after steps 4–6 (E-B2-29, the tester confirmed the reload by repeating it while signed in as P1). After a reload the app returns to the main list instead of the open goal; the case only expects the user to stay signed in.
- UAT-06 step 5: a first attempt pressed Back without clicking Logout, so the session was still active (E-B2-21, E-B2-22). The step was then run as written (E-B2-23 to E-B2-26). Logout ending the session matches UAT-04 step 4d (E-B2-07).
- One screenshot of the browser's new-tab page (step 5, first attempt) was not kept because it showed personal browser data.
- Times in the evidence register are approximate (when the screenshot reached the record), Asia/Bangkok.
